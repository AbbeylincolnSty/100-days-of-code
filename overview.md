# Repository Overview

## General structure
- **README.md**: Landing page with translation links and how to participate in the challenge.
- **rules.md**: The formal #100DaysOfCode commitment and expectations, including updating the start date.
- **log.md** and **r1-log.md**: Daily logging templates you replace with your own entries.
- **resources.md**: Curated learning materials, project ideas, and habit-building articles.
- **FAQ.md**: Answers to common participation questions and tips.
- **intl/**: Translations of the primary docs across multiple languages.

## Important things to know
- Plan to code **at least one hour every day for 100 days**, sharing progress publicly for accountability.
- Keep a public log by updating `log.md` or `r1-log.md` with your own notes instead of the example text.
- Update the placeholder start date in `rules.md` to your actual Day 1.
- Community interaction is encouraged: tweet daily with the hashtag and connect through the linked Slack/Twitter communities.

## Pointers for what to learn next
- Pick material from `resources.md`, including the official #100DaysOfCode guides, habit-building posts, and project idea hubs (e.g., FreeCodeCamp or The Odin Project).
- Explore the book recommendations for mindset and productivity to stay consistent through the challenge.
- Use translations in `intl/` if they suit you better, or contribute a new translation following the README invitation.
